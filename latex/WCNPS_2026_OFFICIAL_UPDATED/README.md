# WCNPS 2026 Updated Manuscript

This folder contains the updated LaTeX source for the WCNPS 2026 paper, incorporating the latest simulation results for the IEEE 30-bus system.

## Changes Made:
1. **IEEE 39-Bus Removed**: Section IV.F and all associated figures were completely removed to keep the focus solely on the IEEE 30-bus system and ensure compliance with page limits.
2. **Numerical Reconciliations**: The MLP (838.44 MW), loadability increase (195.85%), and ANAREDE deviation (0.29%) were updated to match the latest base case.
3. **Tables Updated**: The generated tables for voltage, generation, Spearman correlations, and N-1 rankings were inserted. The L-Index was manually excluded from the Spearman correlation matrix.
4. **Figures Updated**: All .pdf figures generated from the latest run were copied over into the `figures` directory.

## Usage:
Zip this folder and upload it directly to Overleaf. Compile using pdfLaTeX.
